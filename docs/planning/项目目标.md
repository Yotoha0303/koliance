1、技术落地方案：用最稳的模型做出最直观的 Hardcore Demo
不需要从零发明复杂的 AMM 算法，优先选择成熟、稳定、抗风险的模型快速交付：

核心合约模型（单池/金库模式，对标 GMX v1）：

构建一个简单的流动性金库（Vault），支持存入 USDC 作为对手盘。

用户质押保证金，调用合约选择方向（做多/做空美股标的，如 NVDA、TSLA、BTC）与杠杆倍数。

预言机集成（Pyth Network）：

直接采用 Pyth 的 Low-Latency Pull Oracle（Pyth 在各测试网均有极佳支持，且包含主流美股股票价格源）。

交易触发时直接将 Pyth 链下签名更新打包上链，保证零延迟喂价。

链下清算 Bot（用 Go 编写）：

编写一个轻量级的 Go 守护进程，监听链上所有 Open Positions 与 Pyth 实时价格流。

当保证金率低于维持阈值时，并发调用 liquidate() 赚取清算赏金。

路演演示亮点：在前端手动调低模拟价格，大屏幕上展示 Go Bot 在不到 1 秒内高并发完成数十笔头寸的链上自动清算。

2、落地排期与分工建议（以黑客松冲刺为基准）
阶段 1：智能合约与预言机（2-3 天）

完成 Vault.sol（存取流动性）、PositionManager.sol（开仓/平仓/杠杆计算）与 Pyth 喂价接口。

编写 Foundry/Hardhat 测试，跑通开平仓与清算边界条件。

阶段 2：清算 Bot 与后端支持（2 天）

基于 Go 实现高频清算 Bot，加入 WebSocket 实时行情推送服务。

阶段 3：前端交互与演示打磨（2-3 天）

结合现有的 Next.js 前端，补齐 TradingView K线图、开仓/杠杆滑块、实时持仓列表以及一键触发模拟清算的 Demo 控制面板。
