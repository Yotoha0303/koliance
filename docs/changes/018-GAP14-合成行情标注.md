## 缺口：两个合成来源，一个从未显示的字段

`/api/market` 有三条来源路径，其中**两条在本地生成序列**：

| 路径 | 旧 `source` | 实际是什么 |
| --- | --- | --- |
| MON-USD | `monad_oracle_gatekeeper` | **无 oracle 参与**，本地随机游走 + 一个锚定价 |
| 上游失败回退 | `cached_calibrated_mirror` | **既无 cache 也无 calibration**，本地随机游走 |
| Yahoo 成功 | `yahoo_finance_live` | 真实 |

三个问题，按严重度排：

1. **两条合成路径都用 `Math.random()`** —— **同一页面刷新两次，会看到两段不同的价格历史**。
   在一个以「评委必须能验证你造了什么」为立论的项目里，
   **一个看一眼就变的图表比没有图表更糟**。
2. **`source` 字段被读取却从未渲染**（实测：`MarketTerminal.tsx` 里无任何 `.source` 引用），
   而副标题**无条件**写「**· Real-time Technical Analysis**」。
3. **来源名描述的是不存在的机制**：`oracle_gatekeeper` 没有 oracle，
   `cached_calibrated_mirror` 没有缓存也没有校准。

---

## 做了什么

### 1. 确定性替代随机

新增 `seededRandom(seed)`（FNV-1a 播种 + xorshift），
种子为 **`symbol:range:interval:UTC日`**：

- **同一天内同一请求恒定** → 图表可复现、可被第三方核对；
- **跨天推进** → 保留"序列会走"的形态，而不是冻结成常数。

MON-USD 与回退路径都改用它。

> `Math.random()` 在前端测试环境里本就可被 mock，但**mock 掉并不能让它在浏览器里变得可复现**——
> 问题的位置是运行时，不是测试。

### 2. 来源如实标注

| 旧 | 新 |
| --- | --- |
| `monad_oracle_gatekeeper` | **`synthetic_curated`** |
| `cached_calibrated_mirror` | **`synthetic_fallback`** |
| `yahoo_finance_live` | 不变（**且显式 `synthetic: false`**） |

三条路径都带上 `synthetic: boolean` 与 `dataCaveat: string | null`，
让"这条数据是不是生成的"成为**机器可读**的字段，而不是靠人读来源名去猜。

### 3. UI 显示它

- 副标题：合成的显示「Technical Analysis on **Synthetic Data**」，真实的才是「Real-time」；
- `dataCaveat` 存在时，渲染一条琥珀色标注（来源名 + 说明）。

## 负向证伪

把 `seededRandom` 的返回改成 `Math.random()`（即**退回旧行为**）：

```
× returns the same series for the same request, twice in a row
  AssertionError: expected [ 130.69, 131.22, 132.22, …(27) ] to deeply equal [ Array(30) ]
```

**确定性断言如期失败**——这条用例对旧代码**每次都会失败**。工作区已还原（残留标记 0）。
