## 变更内容

### 1. 新增 `PerpConstants.MAX_PROFIT_BPS = 10_000`

利润封顶为名义本金的 100%。

### 2. `Position` 新增 `payoutCapUsd`

```solidity
struct Position {
    address owner;
    bytes32 feedId;
    uint256 collateralUsd;
    uint256 sizeUsd;
    uint256 payoutCapUsd;   // 新增
    uint256 entryPrice;
    bool    isLong;
    uint256 openedAt;
}
```

### 3. `reservedAssets()` 语义变更（**破坏性**）

- **旧**：`openCollateralUsd`（本金之和，下界）
- **新**：`totalPayoutCapUsd`（最大应付额之和，精确值）

### 4. `openPosition` 新增偿付准入

```solidity
if (projectedAssets < projectedReserved) revert InsufficientPoolCapacity();
```

### 5. `closePosition` 付款改为按上限截断，且零额跳过

### 6. `liquidate` 逐笔容错 + 赏金基数改为抵押品（GAP-05）

## 修复后的语义变化（使用者须知）

1. `reservedAssets()` **数值显著变大**：从"本金之和"变为"最大应付额之和"。1x 仓位约为本金的 2 倍，50x 约为本金的 51 倍。
   → **LP 可提取额度相应变小，开仓需要的池子变大。**这是有意的代价，见 ADR-002 §5。
2. 新增 `maxProfitBps()` getter，返回 `10_000`。
3. 新增 event `PositionRewardFailed(uint256 indexed positionId, uint256 rewardUsd)`。
4. `Position` 结构新增字段 `payoutCapUsd`（位于 `sizeUsd` 与 `entryPrice` 之间）。
   → **ABI 变化。**本模块尚未部署（`deployed_addresses.json` 仅含身份合约），无迁移成本；且本批未改动 `ignition/modules/PerpStack.ts`。
